# SQL-Candidate-Database-Analysis
This project involves Creating, Analysing and Exploring Candidate Database information using PostgreSQL.

# Project Highlight
- This Dataset contains information about Student_ID, First Name, Department, Gender, Age, Scores, Attendance and Study hours of all the Candidates.

# Tools and Skills
- PostgreSQL
- coding Languages

# Dataset discription
The dataset contains the following columns:
- Student_ID
- First Name
- Department
- Gender
- Age
- Scores
- Attendance
- Study hours
